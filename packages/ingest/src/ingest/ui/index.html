Ingest

1. Options

Collection = domain. Everything you ingest goes into this collection, and the chat searches the collection you pick. Use one per company or project to keep their data apart. A new name is created by its first ingest.

Language only affects the keyword (BM25) side. Use none for a language that is not listed. A collection keeps one language and one embedding model.

2. Files

    Ingest path reads files from a folder on the computer that runs this server (not from your browser). Only folders listed in INGEST_ALLOWED_PATHS are allowed.
